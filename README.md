# Projekt A – Hangman

Et ordgættespil lavet med HTML, CSS og JavaScript uden biblioteker.

## Sådan spiller du

Åbn `index.html` i en browser. Læs ledetråden, og vælg et bogstav. Rigtige bogstaver vises i ordet. Ved hvert forkert gæt tegnes en del af figuren. Du vinder, når hele ordet er fundet, og taber efter seks forkerte gæt. Knappen **Nyt ord** starter et nyt spil.

## Sådan virker projektet

- `index.html` indeholder sidens opbygning og spillets elementer.
- `styles.css` styrer udseende og visning på mobil og computer.
- `script.js` vælger et ord, behandler gæt og opdaterer spillet på siden.

Ord og ledetråde kan ændres øverst i `script.js`.

## Brug af AI

AI er brugt som hjælpemiddel i projektet, især til CSS og det visuelle design, men også en smule til JavaScript.
